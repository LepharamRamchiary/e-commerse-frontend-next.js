# Description
This is a beginner-friendly frontend e-commerce website built using Next.js. It provides a clean, modern interface for users to browse. The project is ideal for those learning frontend development and offers a simple, responsive layout.

The website is not hosted, so to view it, you will need to clone the repository and run it on your local machine. It demonstrates the use of modern frontend technologies like React, Next.js, and Tailwind css for styling.

## Getting Started

#### First, clone the repo:

```bash
git clone https://github.com/LepharamRamchiary/e-commerse-frontend-next.js
```
#### Second, Navigate to the project directory:
```bash
cd e-commerse-frontend-next.js
```
#### Third, Install dependencies:
```bash
npm install
```
#### Four, Start the development server:
```bash
npm run dev
```
